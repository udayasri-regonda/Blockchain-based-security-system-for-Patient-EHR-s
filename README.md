## ⚙️ Smart Contract — What's New

### New Functions (vs original)

| Function | Description |
|---|---|
| `registerDoctor(addr, name, specialization)` | Admin registers doctor with specialization |
| `getDoctorDetails(addr)` | Returns name, spec, isRegistered, timestamp |
| `isDoctor(addr)` / `isPatient(addr)` | Boolean role check — used for auto role detection |
| `registerPatient(..., bloodGroup, contactNumber)` | Extended registration with 2 new fields |
| `updatePatientDetails(age, blood, contact)` | Update personal info on-chain |
| `getPatientDetails()` | Now returns 7 fields (added blood, contact, timestamps) |
| `getStats()` | Returns (totalPatients, totalDoctors, totalTransactions) |
| `getAdmin()` | Returns current admin address |
| `getAccessLogCount()` | Admin: total on-chain access events |
| `getAccessLog(index)` | Admin: read individual log entry |

### Events
- `PatientRegistered`, `PatientUpdated`, `DoctorRegistered`
- `DoctorAuthorized`, `DoctorRevoked`, `EmergencyAccess`, `AdminChanged`

## 🚀 Setup Guide

### Prerequisites
- [Node.js 18+](https://nodejs.org)
- [Truffle](https://trufflesuite.com): `npm install -g truffle`
- [Ganache](https://trufflesuite.com/ganache/) (GUI or CLI)
- [MetaMask](https://metamask.io) browser extension

---

### Step 1: Install root dependencies

```bash
cd ehr-blockchain-unified
npm install
```

---

### Step 2: Start Ganache

**Option A — Ganache GUI:**
1. Download from https://trufflesuite.com/ganache
2. Create a new workspace
3. Ensure it runs on port **7545**

**Option B — Ganache CLI:**
```bash
npm install -g ganache
ganache --port 7545 --networkId 1337
```

---

### Step 3: Configure Admin Address

Open `contracts/Healthcare.sol` and look at the constructor:

```solidity
constructor() {
    admin = msg.sender;  // deployer becomes admin automatically
}
```

The deployer's address (first Ganache account) will be admin. ✓

---

### Step 4: Compile & Deploy Smart Contract

```bash
# From project root:
npm run compile   # Compiles contract, outputs Healthcare.json to client/src/
npm run migrate   # Deploys to Ganache on port 7545
```

You should see output like:
```
Deploying 'Healthcare'
   ─────────────────────────────
   > transaction hash: 0xabc...
   > contract address: 0x123...
   > block number: 1
```

---

### Step 5: Connect MetaMask to Ganache

1. Open MetaMask → Networks → Add Network
2. Set:
   - **Network Name**: Ganache Local
   - **RPC URL**: `http://127.0.0.1:7545`
   - **Chain ID**: `1337`
   - **Currency Symbol**: ETH
3. Import one of Ganache's private keys (shown in Ganache dashboard) into MetaMask

---

### Step 6: Start the React Frontend

```bash
cd client
npm install
npm start
```

Open: **http://localhost:3000**

## 🧪 Testing Each Feature

### 1. Auto Role Detection
- Connect first Ganache account → MetaMask → you are **Admin**
- Connect account that deployed via `registerPatient` → **Patient**
- Connect account registered by admin via `registerDoctor` → **Doctor**
- Connect any other account → **Guest**

### 2. Admin Panel (`/admin`)
- Register a doctor (enter a Ganache address + name + specialization)
- Check live stats update after registration

### 3. Register Patient (`/register`)
- Connect a different MetaMask account (not admin)
- Fill name, age, blood group, contact, medical history
- Confirm MetaMask transaction
- On success → redirect to profile

### 4. Patient Profile (`/profile`)
- View all your on-chain data
- See list of authorized doctors with their names

### 5. Access Control (`/authorize`)
- Grant access: enter the doctor's Ethereum address → Authorize
- Revoke access: enter same address → Revoke
- Check status: enter address → verify boolean on-chain

### 6. Update History (`/history`)
- Change medical history or personal details
- Each update is a separate blockchain transaction

### 7. Doctor Patients (`/doctor`)
- Log in as the registered doctor account
- See all patients who authorized you
- Click any patient → view their full record

### 8. Audit Logs (`/logs`)
- Log in as admin
- See every GRANT, REVOKE, EMERGENCY event with address + timestamp

## 🔐 Security Model

```
Patient registers  →  stores data on Ethereum
                       (only patient can call)
                       
Admin registers doctor  →  doctor gets isRegistered = true
                            
Patient authorizeDoctor(addr)  →  authorizedDoctors[patient][doctor] = true
                                    (logged: AccessLog.GRANT)
                                    
Doctor calls getPatientDetails(addr)  →  modifier checks authorization
                                          reverts if not authorized
                                          
Patient revokeDoctorAccess(addr)  →  authorizedDoctors[patient][doctor] = false
                                       (logged: AccessLog.REVOKE)
                                       
Admin emergencyAccess(addr)  →  bypasses auth, logs EMERGENCY on-chain
```

## 📦 Deploy to Sepolia Testnet

1. Install provider: `npm install @truffle/hdwallet-provider dotenv`
2. Create `.env`: 
   ```
   MNEMONIC=your twelve word mnemonic here
   INFURA_PROJECT_ID=your_infura_key
   ```
3. Uncomment the Sepolia config in `truffle-config.js`
4. Run: `truffle migrate --network sepolia`
5. Update `client/src/Healthcare.json` with the new network entry
